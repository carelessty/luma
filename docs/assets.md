# Asset credits

## Project artwork

`macos/Resources/Media/hero.jpg` and the six `poster-*.jpg` files are fictional demo artwork created for Luma with OpenAI image generation. The associated titles and metadata are fictional. These project assets are distributed under the repository's [GPL-3.0-or-later license](../LICENSE).

The application icon is a project-created geometric play symbol. Its vector source is `macos/Resources/AppIcon.svg`; the macOS icon is `macos/Resources/AppIcon.icns`.
